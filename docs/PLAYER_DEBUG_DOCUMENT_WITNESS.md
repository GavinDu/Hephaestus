# DEBUG native document witness (#805)

Only DEBUG builds launched with the existing `--ui-test-scene-trace` flag append a document-start script that sends four bounded observations through the existing handler. The pool consumes the dedicated message type before any game callback, checking current view, exact frame request URL, main frame, origin, credential scope, native nonce and current routing lease. No error text, resource URL, private payload or arbitrary event name is recorded. The witness is not a trusted game metric, attestation or readiness signal. It can distinguish observed transport/document activity from absent scene submission; missing witness is inconclusive (including navigation ordering or script/handler failure). No release code injection, new handler name, new native command or test assertion change. Revert this commit to remove it. Genuine device CI and deployed producer correlation remain required.
