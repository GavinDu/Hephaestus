# #770 incremental native terminal no-scene cleanup (successor Epic #642)

This narrowly scoped source change removes the real mounted PlayerWebView from the active SwiftUI view hierarchy when the current attempt's 12-second no-scene watchdog reaches terminal recovery. Previously the error card was overlaid while the WebView remained mounted.

The pure PlayerTerminalNoSceneMountPolicy rejects only the exact terminal attempt. SwiftUI dismantle invokes the existing Coordinator stopObserving() and PlayerWebViewPool.recycle(webView, lease: coordinator.attachmentLease), which is guarded by ownsActiveAttachment. This cancels the Coordinator's metric/result fetch tasks, detaches the receiver, invalidates document nonce/scene ledger, stops the WebView and loads blank HTML. A later manual Retry increments attempt, so it can take a NEW attachment lease; stale teardown cannot recycle the successor. All eight currently installed sheet callbacks (progress, navigation finish/failure, termination, prewarm, scene, first input and verified result) ignore the terminal epoch before mutation. The poster-independent deadline remains separate #791.
