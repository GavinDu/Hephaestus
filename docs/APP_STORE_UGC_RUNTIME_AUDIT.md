## Source discrepancies to correct before release

- [GAME_PACKAGE_ARCHITECTURE.md](./GAME_PACKAGE_ARCHITECTURE.md) currently claims the player is “bridgeless” with **no** WKScriptMessageHandler, while production [PixiPlayer.swift](../Hephaestus/Player/PixiPlayer.swift) has one narrowly validated handler. Correct architecture docs and App Review description; distinguish telemetry/result messages from arbitrary native platform APIs.
- Do not mistake `WKNavigationDelegate.didFinish` or `first_scene_render_submit` for OS GPU composition. Hardware measurements remain [#204](https://github.com/GavinDu/Hephaestus/issues/204).
- Trust and freshness are separate: [native #238](https://github.com/GavinDu/Hephaestus/pull/238) v2 document token still admits old schema v1 until first v2 event. Strict v2 rollout / 128+ actual WebKit adverse navigation tests remain [#203](https://github.com/GavinDu/Hephaestus/issues/203).
- A replay-input hash is not independently verified score. [Generator #360](https://github.com/GavinDu/html5-game-generator/issues/360) must implement independent bounded server-owned replay and verdict.

## Proposed acceptance and artifacts

1. Moderation/UGC owner demonstrates content filtering before publish, report response/appeal, block, removal/takedown and cache purge with backend request/response logs and iPhone+iPad screenshots.
2. Platform owner proves universal-link domain entitlement, AASA deployment, canonical per-game index plus private/removed-game rejection, and iPhone/iPad incoming link handling.
3. Policy owner defines game-specific rating metadata, actual age restriction flow (verified or declared age) and server-side denial on all entry paths; tests for anonymous/underage/expired sessions.
4. Native reviewer catalogs every script bridge event, scopes it to trusted origin, evaluates 4.7.2 permission issue, records App Review guidance or necessary remediation; no unreviewed new native control API.
5. Privacy owner validates consent/policy/retention/deletion and telemetry paths. QA provides real-device performance, thermal and 50+ lifecycle evidence, and all required GitHub Actions green.

**Senior game-engine architecture challenger verdict:** **Conditional architecture direction; App Store 4.7 audit NOT passed.** Existing report/block affordances are concrete, but universal-link, age-gate, runtime policy/bridge classification, moderation operations, and hardware acceptance are not proven. Keep Epic #202 open. This source-based checklist does not certify that Apple will accept the app.
